# Genuine Silky frontend integration

The installed theme is the original **Silky by DiMo** from official OnionUI/Themes commit `b01198352e8927c3c5b9a828f73177bc81745954`. Its archive SHA256 is `2963e51338f5a09b4d3a66980a43ef507fb44449a9af5d5c8d542a0897d716b7`. Original `config.json`, PNGs, and author credits are preserved. `SOURCE.json` records provenance. Stock Exo Universal and WenQuanYi Micro Hei font files and default system icons are from Onion commit `07505ea58c7bba698d6b9220ff43946a43cac76b`; their individual hashes/source URLs are included. `moss.override.json` is a separate, original compatibility palette/layout overlay.

The executable is a native C SDL2 implementation. It does not execute Onion's ARM32 proprietary MainUI or arbitrary theme scripts. It renders Silky's actual normal/focused PNG cards for Favorites, Games, Apps, Settings and its actual status/background/GameSwitcher assets. The TTF engine opens bounded immutable font buffers via SDL_RWFromConstMem/TTF_OpenFontRW and renders UTF-8 using the actual Moss SDL2_ttf runtime. Legacy `/mnt/SDCARD/miyoo/app/<font>` references are safely rebased to the selected theme's `fonts/` directory. Font paths cannot escape the asset root. Font/image decode failure retains the built-in renderer fallback.

Controller workflow: the physical verification wizard runs first when required. MainUI opens afterward; Left/Right or L1/R1 select the four cards, A opens, B returns. Games shows scanned and registered titles, system-logo PNGs, list/grid layouts and selected box art. A preserves existing verified launch/checkpoint authorization; X opens states; Y opens game actions, including Toggle Favorite. Favorites is filtered against the current discovered/registered library. MENU from MainUI opens recent GameSwitcher; in-game MENU lifecycle remains owned by the supervisor/daemon/RetroArch bridge.

Apps offers functional GameSwitcher, Refresh ROM library, Storage recovery actions. Settings offers a session list/grid toggle, physical controller recheck, Storage recovery, and orderly Power off. No Package Manager, Activity Tracker, network installer, or arbitrary root-code launcher is painted as a working feature. Settings' view choice is currently session-scoped; persistent overrides can be supplied through the existing configured JSON override path.

Favorites is stored at `/mnt/SDCARD/Saves/CurrentProfile/favorites.json` with a versioned, bounded list of at most 50 game identities. A dedicated worker performs all reads and writes; the SDL event loop never waits on card I/O. Mutations use unique exclusive temporary files, complete writes, file fsync, atomic rename, and directory fsync. Only EINVAL/EOPNOTSUPP on a verified FAT filesystem permits syncfs fallback. A failed mutation preserves the prior committed snapshot and produces a visible error. Malformed records are never silently overwritten. Queued preferences drain before the UI process exits. Missing cards/directories fail cleanly.

Display compatibility is limited to the actual Moss vendor `mali` backend: its documented NPOT texture promotion may be accepted up to 2048x2048 while locking, clearing and rendering only the logical 640x480 rectangle. Other drivers still require exact dimensions. Mali uses SDL_WINDOW_SHOWN to match the zero28 reference implementation. Accelerated/vsync checks remain; software fallback requires the existing explicit qualification setting. Texture promotion is logged. This source evidence is not a claim of physical display qualification.

Native Windows SDL/SDL_ttf fixture execution passed using the actual PNGs/fonts and produced the previews in `previews/Silky/`; each was visually checked. The AArch64 production warning-as-error build passed and produced actual console-launcher and GameSwitcher executables. A separate AArch64 surface-only fixture and Favorites persistence fixture are provided for isolated execution with the actual Moss libraries; target results are recorded by the image validation workflow. Physical handheld rendering/input remains unverified.

Remaining full-Onion parity gaps include Package Manager, Activity Tracker, broad app suite, system-folder drilldown, complete theme property coverage, and physical hardware qualification. The Games and Favorites snapshots retain the existing 50-entry UI bound. GameSwitcher does not substitute box art for missing frame captures; absence is explicitly shown. The original bottom skin's baked Miyoo X/SELECT legends are covered at render time, retaining the divider and original unmodified PNG; the displayed A/Y/B/Left-Right mappings match this frontend.
