# CloveOS credits

CloveOS is an independent community project for the MagicX Mini Zero 28. Its interface and workflow draw on OnionOS, with hardware and runtime foundations from the Moss and oakMOSS projects and emulator support from RetroArch and libretro cores.

- [OnionUI / Onion](https://github.com/OnionUI/Onion) provides the reference workflow and adapted components.
- [Moss Zero 28](https://github.com/shauninman/Moss-zero28) provides the original device foundation.
- [oakMOSS](https://github.com/spruceUI/oakMOSS) provides the matched kernel and runtime components used by the test image.
- [MinUI](https://github.com/shauninman/MinUI) informed the handheld architecture and supplied upstream build inputs.
- [RetroArch](https://github.com/libretro/RetroArch) and the [libretro projects](https://github.com/libretro) provide emulator infrastructure and cores.
- Silky is by DiMo and is sourced from [OnionUI / Themes](https://github.com/OnionUI/Themes).
- Additional components include SDL, uMTP-Responder, and the SMB/SFTP libraries recorded in the build's provenance and notices.

The supplied house-and-hatchets splash is the CloveOS artwork selected by the project maintainer.

This initial repository setup documents the test build. The exact corresponding source, patches, build inputs, and component notices are still being assembled. [REDISTRIBUTION.md](REDISTRIBUTION.md) records the open items. A complete component inventory and matching notices belong with the source release.
